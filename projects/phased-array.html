28 GHz phased array for 5G beam steering

A 16-element mmWave antenna array modeled in Ansys HFSS, used to study how far a beam can be steered electronically and what it costs.

This project is in progress. I'll add measured and simulated results as I finish each stage.

Why this project

Phones and base stations working at 28 GHz can't rely on a fixed antenna pattern: the path loss is high, so they point narrow beams at each user and steer them as people move. I wanted to see those tradeoffs directly rather than only in equations, so I'm building the array up in simulation one piece at a time, starting from a single element.

What I'm doing

  • Single element. I started from a stacked microstrip patch, which gives more bandwidth than a single patch, and tuned it in HFSS for a good match around 28 GHz.
  • The array. Arranging 16 elements in a 4 × 4 grid and setting the element spacing so the beam can scan without grating lobes.
  • Beam steering. Applying progressive phase shifts across the elements and tracking gain, beamwidth, sidelobe level and scan loss at each steering angle.
  • When things go wrong. Adding phase-shifter errors and switching off individual elements to see how gracefully the beam degrades.
  • Real constraints. Relating the results to what actually limits 5G base-station and handset designs: size, element count and cost.
