Automatically tuned HF magnetic loop antenna

Our senior project: a compact loop antenna that covers 7–14 MHz by retuning itself, designed for Hascall-Denke for military use.

This project is in progress. Results and prototype photos will go here as we build and test.

The problem

A full-size antenna for 7 MHz is around 20 meters long, which isn't practical to carry or set up quickly. A small magnetic loop fits in a fraction of that space, but its bandwidth is so narrow that it has to be retuned for almost every frequency change. Our job is to make that retuning automatic so the operator never has to touch it.

Approach

  • Loop geometry. Sizing and optimizing the loop in Ansys HFSS, looking at gain, bandwidth, efficiency and radiation pattern across the band.
  • Matching. Designing a matching network that presents a nominal 50 Ω to the radio.
  • Tuning. An electrically actuated tuning element that moves the resonance to whatever frequency is being used.
  • Build and test. Prototyping the antenna and checking it on a VNA against the simulation.

Results

Coming soon: simulated and measured return loss across 7–14 MHz, efficiency, and how quickly the system retunes.
